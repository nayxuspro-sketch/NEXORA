LISEZMOI - « MAGASIN INTROUVABLE DANS VOTRE ENTREPRISE » EN CAISSE
===============================================================

LE MESSAGE QUE VOUS AVEZ RECU
    Echec de la transaction
    Magasin introuvable dans votre entreprise

CE QUI SE PASSE VRAIMENT (verifie sur le code, puis reproduit en test)
  1. Le POS lit la liste des caisses et prend LA PREMIERE. Si cette liste est
     VIDE, il utilise une caisse INVENTEE : « Caisse Comptoir Principal »,
     code REG-01, identifiant « reg-01 », magasin « store-01 », solde
     125 000 F. Elle ressemble a une vraie caisse, mais n'existe pas en base :
     le serveur refuse alors CHAQUE vente. Le message en caisse devrait etre
     « aucune caisse », pas « magasin inconnu » : le vrai probleme etait
     masque.
  2. Le serveur, lui, est coherent : une vente doit porter un magasin reel de
     VOTRE entreprise (garde de securite livree precedemment). Le message
     exact « Magasin introuvable dans votre entreprise » apparait quand le
     magasin envoye appartient a une AUTRE entreprise — reproduit en test.
  3. Une deuxieme cause, plus grave, a ete trouvee et corrigee : le serveur
     laissait creer une caisse rattachee au magasin d'une AUTRE entreprise
     (reproduit : creation acceptee en 201 au lieu d'un refus). Une telle
     caisse envoie ensuite ce magasin etranger a chaque vente, d'ou votre
     message. C'est desormais refuse (400, message explicite).
  4. Enfin, si la vente n'indiquait pas de magasin, le serveur prenait le
     PREMIER magasin de l'entreprise : la vente pouvait donc etre rattachee a
     un autre magasin que celui de sa caisse (rapport Z et cloture fausses).
     C'est corrige : le magasin de la CAISSE fait foi.

ENSUITE, DANS L'APPLICATION
  1. Redemarrez le backend (le controle serveur doit prendre effet), puis
     relancez le frontend et faites Ctrl+F5.
  2. Ouvrez la caisse : si elle est vide, l'ecran vous propose de creer le
     magasin puis la caisse. La nouvelle caisse ouvre sa session
     automatiquement (fond de caisse 0, modifiable).
  3. Enregistrez une vente : elle part avec SA caisse ; le magasin est deduit
     de la caisse, donc plus aucun message « Magasin introuvable ».
  4. Si votre base contient deja des caisses mais rattachees a une autre
     entreprise (le diagnostic le dit), creez une caisse dans la bonne
     entreprise depuis l'ecran du POS : plus besoin de toucher a la base.

Guide Officiel de Déploiement NEXORA

Ce guide vous accompagne pas à pas pour installer et déployer la plateforme commerciale et Point de Vente NEXORA sur votre ordinateur personnel, en réseau local ou sur un serveur de production.

Devise configurée : Franc CFA (XOF / FCFA)
Fiscalité UEMOA : TVA standard à 18%
Paiements inclus : Espèces, Mobile Money (Orange Money, Moov Money), Ventes à crédit

Mode 1 : Déploiement Local Simple (1 Clic - Débutant)

Ce mode utilise Python + Django + SQLite3. Aucune installation de base de données externe n'est requise.

A. Sous Windows :

  1. Téléchargez et décompressez l'archive nexora-release-v1.0.0.zip.
  2. Ouvrez le dossier NEXORA.
  3. Double-cliquez simplement sur le fichier start-local.bat.
  4. Le script installe automatiquement l'environnement virtuel, les dépendances et démarre le serveur.

B. Sous Linux ou macOS :

  1. Extrayez l'archive :
    tar -xzf nexora-release-v1.0.0.tar.gz
    cd NEXORA
  2. Exécutez le script automatisé :
    ./start-local.sh

C. Lancement de l'Interface Web (Next.js) :

Dans un second terminal, rendez-vous dans le sous-dossier frontend/ :

cd frontend
npm install
npm run dev

Ouvrez ensuite votre navigateur sur : http://localhost:3000

Mode 2 : Déploiement Professionnel avec Docker (Production / VPS)

La stack conteneurisée complète comprend : PostgreSQL 16, Redis 7, Backend Django Gunicorn et Frontend Next.js.

# 1. Copier le fichier de configuration d'environnement
cp .env.example .env

# 2. Lancer tous les conteneurs en tâche de fond
docker compose up -d --build

Sauvegarde et Restauration

Pour effectuer une sauvegarde complète des données :

./scripts/backup.sh

Pour restaurer une sauvegarde :

./scripts/restore.sh ./backups/nom_du_fichier.db

Vérification de Santé (Healthcheck)

Pour vérifier l'état du serveur et la connexion à la base de données :

curl http://localhost:8000/api/v1/health/

# Installation locale

Le guide d’installation Windows a été regroupé et corrigé dans [`INSTALLATION-COMPLETE-NEXORA.md`](INSTALLATION-COMPLETE-NEXORA.md).

À retenir : `start-local.bat` ne crée pas l’environnement virtuel, n’installe pas les dépendances et n’exécute pas les migrations. Effectuez d’abord les étapes de préparation décrites dans le guide. La base incluse dans une nouvelle installation est vide ; aucune base utilisateur n’est distribuée.
